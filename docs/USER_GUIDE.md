## 1. 🎯 这款软件是为谁设计的？（核心用途）

传统监控软件往往功能割裂：**MSI Afterburner** 偏向显卡超频且界面较复杂；**任务管理器** 无法常驻游戏内；市场上更没有任何一款工具能够**同时监控硬件状态与本地运行的 AI Agent (如 Google Antigravity)**。

**Monitor** 正是为了打破这种割裂而生：
* 🎮 **PC 游戏玩家**：在 3D 游戏（DirectX 9/11/12、Vulkan、OpenGL）中实时掌握平均帧率 (FPS) 与 **1% Low 掉帧卡顿**、显卡功耗墙与温度，开启**鼠标穿透**后常驻屏幕且绝不阻挡瞄准射击；
* 🤖 **AI 工程师 / Antigravity 深度用户**：实时追踪当前活跃会话的 **Token 上下文容量水位**（防范模型记忆劣化）、拆解思考/工具执行占比、统计当日消耗量并按 Gemini 官方阶梯费率估算使用成本；
* 💻 **硬件极客与发烧友**：18 线程独立热力图矩阵直观查看大小核调度，直调 NVIDIA NVML 获取 P-State 性能挡位与物理/虚拟内存提交；
* ⚡ **日常办公与系统维护**：轻量低开销（采集常态 CPU < 0.2%），提供一键清理内存工作集缓存功能。

## 2. 🚀 启动方式详解（静默 / 调试 / 开机自启）

项目根目录下提供了多种启动方案，满足日常使用、问题排错与自动化需求：

| 启动方式 | 对应文件 / 命令 | 适用场景 | 特点 |
| :--- | :--- | :--- | :--- |
| **日常静默启动** | `启动Monitor.bat` | 日常打游戏、写代码或办公 | **无黑色控制台窗口**，静默拉起托盘与悬浮条；若缺少虚拟环境会弹出中文操作指引 |
| **调试排错启动** | `调试启动.bat` | 首次运行、显卡未识别或报 Bug | **保留黑色命令行窗口**，实时输出驱动探活、采样日志与报错堆栈，适合截图反馈 |
| **一键自动化测试** | `运行测试.bat` | 代码修改后验证功能 | 一键运行 12 项单元测试，验证 RTSS 算法、NVML 驱动与 AI 计价逻辑是否正常 |
| **开发者命令行** | `uv run monitor` 或 `.\.venv\Scripts\python.exe run.py` | 终端开发者模式 | 支持 uv 极速包管理 |

### 💡 技巧：如何设置 Windows 开机无感自启？
1. 在根目录下的 **`启动Monitor.bat`** 上单击右键，选择 **创建快捷方式**；
2. 按键盘快捷键 `Win + R`，输入 `shell:startup` 并回车，打开 Windows 系统的「自启动文件夹」；
3. 将刚才生成的快捷方式剪切粘贴进该文件夹中；
4. 以后每次电脑开机，Monitor 就会在后台静默启动并自动贴边待命！

## 3. 🖼️ 三大悬浮 HUD 指标全景图文拆解

Monitor 提供了三种可以在屏幕任意位置吸附停靠的 HUD 模式。在悬浮窗上单击鼠标右键即可自由切换：

### 形态 1：横向流线型胶囊栏 (Horizontal Pill) —— 旗舰全景

![横向胶囊栏](../assets/screenshots/hud_horizontal.png)
*(游戏运行态)*

![横向胶囊栏 AI 态](../assets/screenshots/hud_horizontal_ai.png)
*(AI 活跃态)*

**各分区数值含义对照**：
1. **渲染帧率与 1% Low**（如 `124 · 88L`）：
   - `124`：当前 3D 游戏的即时平均帧率 (FPS)；
   - `88L`：**1% Low 长尾卡顿帧率**。严格基于 RTSS 1024 槽环形微秒帧时间计算，数值越接近平均帧率说明画面越丝滑；若骤降说明产生掉帧微卡顿；未开游戏时显示 `--`；
2. **CPU 与 60 秒平滑走势**（如 `~ 15%`）：
   - 绿色波形折线 (Sparkline) 实时呈现最近 60 秒 CPU 利用率动态，并跟随负载智能变色；
3. **GPU 核心与显存**（如 `GPU 45%` / `P0`）：
   - 包含 NVIDIA 核心利用率、显卡运行功耗 (W) 及当前性能档位（P0 满血 / P8 待机）；
4. **内存状态**（如 `MEM 8.5G`）：
   - 物理内存使用量与已提交虚拟内存 (Commit Charge)；
5. **AI 遥测徽标**（如 `AI 185.5k / 17.5%`）：
   - 当前 Google Antigravity 活跃会话持有的实际上下文 Tokens 及其在 100 万窗口中的占比；
6. **Token 今日与累计消耗**（如 `TOK 774k/1.88M`）：
   - 紧凑微组件：斜杠左侧为今日产生总 Token，右侧为历史全量累计 Token；
7. **游戏网络与 Ping 延迟**（如 `Ping 18ms` · `↓ 1.2M` · `↑ 150K`）：
   - 极轻量 Socket 握手延迟探测（绿 <50ms / 黄 <100ms / 红 >100ms），实时上下行吞吐。

## 4. 🎮 游戏玩家专属：鼠标穿透模式 (Click-Through)

这是专为 FPS、MOBA 等竞技玩家打造的核心体验：

### 为什么需要鼠标穿透？
在打游戏（如 CS2、永劫无间、Apex、黑神话等）时，如果悬浮窗浮在游戏画面上，鼠标甩枪或点击一旦误点到悬浮条，就会导致游戏失焦甚至切出桌面跳出游戏！

### 如何使用：
1. **开启穿透**：右键悬浮窗 ➔ 勾选 **「鼠标穿透模式」**；
2. **效果**：悬浮窗继续常驻在屏幕顶层显示，但**对鼠标完全透明**！您的任何点击、拖拽、右键操作将全部直接穿透并作用在背后的游戏或网页上，绝不干扰游戏微操；
3. **如何关闭穿透/重新移动悬浮窗**：
   - 因为此时鼠标无法直接点击悬浮窗，只需在屏幕右下角任务栏中找到 **Monitor 系统托盘图标**；
   - 在托盘图标上右键 ➔ 取消勾选 **「鼠标穿透模式」**，悬浮窗便恢复可拖拽状态。

## 5. 📊 专业中枢仪表盘四大功能看板

在悬浮窗上**双击鼠标左键**，或通过托盘菜单点击**「显示/隐藏仪表盘」**，即可展开专业级性能中枢：

### 看板 1：📈 性能走势曲线 (Curves)
![性能走势曲线](../assets/screenshots/dashboard_curves.png)
* 原生 `QPainter` 硬件加速绘制，零外部依赖，平滑呈现最近 60 秒的 **CPU 负载、GPU 负载、显卡功耗、游戏 FPS 帧率、网络流量**；
* 实时标注曲线波峰与波谷极值（Min / Avg / Max），帮助排查游戏瞬时掉帧或显卡撞功耗墙的时间点。

### 看板 2：💻 硬件全景与核心拓扑 (Hardware)
![硬件全景与核心拓扑](../assets/screenshots/dashboard_hardware.png)
* **CPU 18 线程独立热力图矩阵**：自动识别大核 (P-Core) 与小核 (E-Core) 的当前占用，一眼定位是否发生多线程调度不均或单核性能瓶颈；
* **GPU 功耗墙监测**：动态条对比当前功率与 TDP 限制上限；
* **3D 进程与掉帧诊断**：直读当前前台全屏游戏进程名称。

### 看板 3：⚡ 进程与系统工具 (Processes)
![进程与系统工具](../assets/screenshots/dashboard_processes.png)
* **资源大户识别**：实时列出消耗 CPU / RAM 最高的进程；
* **🧹 整理内存按钮**：点击直接调用 Windows 底层 `EmptyWorkingSet` 接口，瞬间释放各类后台冗余占用的物理内存工作集。

### 看板 4：🤖 Google Antigravity AI Agent 深度遥测中枢
![Google Antigravity AI 遥测面板](../assets/screenshots/dashboard_antigravity.png)
* **上下文容量健康水位**：实时监控对话持有的 Token 总量，支持 100 万大模型上下文窗口，安全蓝 / 预警黄 / 告警红三阶变色；
* **Token 结构精细剖析**：直观拆解用户输入 (User)、模型生成代码 (AI)、深度思考 (Thinking) 以及工具执行返回 (Tool Results) 的占比；
* **单轮增量与今日消耗**：实时捕捉每一步操作消耗的 Tokens 并换算为 Gemini 官方计费金额（美元 / 人民币）；
* **历史会话漫游定位**：列表展示最近对话记录，支持一键在资源管理器中定位脑区日志。

## 6. 🔔 系统托盘与便捷菜单

Monitor 会在 Windows 任务栏通知区（右下角托盘）常驻微型状态图标：

* **悬停浮窗 (Tooltip)**：鼠标悬停在托盘图标上，即刻弹出硬件与 AI 综合微型看板，包含实时温度、网络上下行、AI 单轮增量与今日折算费用；
* **右键快捷菜单**：
  * **切换 HUD 形态**：在横向胶囊栏、垂直边栏、极简徽章间秒切；
  * **鼠标穿透模式**：随时一键开启/解除鼠标穿透；
  * **锁定悬浮窗位置**：防止日常使用中误拖动；
  * **调节透明度**：支持 30% ~ 100% 透明度滑动；
  * **打开 Antigravity 脑区**：快速打开 AI 会话持久化目录。

## 7. ❓ 常见问题与排错指南

#### Q1: 启动时 3D 游戏帧率与 1% Low 显示为 `--`？
* **原因**：当前未运行 3D 游戏，或尚未运行 RTSS (RivaTuner Statistics Server)。
* **解决**：推荐在后台运行 [RTSS (微星小飞机配套工具)](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/)。启动游戏后，Monitor 将在 0.01 毫秒内自动捕获帧率并开始计算 1% Low；未开游戏时显示 `--` 是为了实现 0% 的待机开销。

#### Q2: 显卡功耗、温度或显存频率未显示？
* **说明**：此功能深度依赖 NVIDIA NVML 驱动。请确保使用的是 NVIDIA 独立显卡并安装了官方 GeForce Game Ready 或 Studio 驱动程序。若为 AMD 显卡或纯核显环境，软件会自动优雅隐藏显卡高级指标，CPU 与网络等功能依然全功能运行。

#### Q3: 遇到报错或程序异常闪退怎么办？
* 请先关闭软件，然后双击运行 **`调试启动.bat`**；
* 查看黑框控制台中打印的初始化与报错信息，截取终端日志并在 GitHub 提交 [Issue](https://github.com/zhenglan843-jpg/Monitor/issues)，我们将第一时间为您修复解答！
