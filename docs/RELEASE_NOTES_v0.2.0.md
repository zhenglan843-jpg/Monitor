## 🌟 核心更新亮点

### 1. ⌨️ Win32 原生全局快捷键（全屏游戏免切屏微操）
过去开启「鼠标穿透 (Click-Through)」后，虽然游戏微操不再被遮挡，但如需移动窗口或退出穿透，必须切出游戏到任务栏托盘操作。  
现在通过底层的 Win32 `RegisterHotKey` 原生机制，为您带来**极速、零外部重型依赖的全局快捷键**：

* **`Ctrl + Shift + P`**：**一键切换 鼠标穿透 / 交互模式**  
  * 打游戏时按一下，立即穿透；需要拖动换位置时再按一下，瞬间恢复交互！
* **`Ctrl + Shift + H`**：**一键 显示 / 隐藏 HUD 悬浮窗**  
  * 需要截取全景屏幕或临时隐藏桌面元素时一秒隐身，再次按下秒恢复。
* **`Ctrl + Shift + D`**：**一键 展开 / 收起 详细中枢仪表盘**  
  * 键盘一键快速呼出 Pro Hub 详细硬件与走势看板。

---

### 2. 💾 本地配置自动持久化 (Settings Persistence)
* 自动记录用户最后一次使用的 **HUD 形态 (横向胶囊/垂直边栏/极简徽章)、屏幕停靠坐标 `(x, y)`、透明度、窗口置顶、位置锁定、采样频率与穿透状态**；
* 配置保存在 `%APPDATA%\Monitor\config.json` 中，软件重启或电脑重启后**自动无缝还原**，再也不需要每次开机重复拖动！

---

### 3. 🚀 一键开启 Windows 开机无感后台自启
* 在仪表盘「⚡ 进程与设置」以及系统托盘快捷菜单中，新增 **「开机无感自启」** 选项；
* 点击即可自动向 Windows 注册表注入免黑框后台静默启动参数，开机即可贴边待命。

---

### 4. 📊 Antigravity AI 彩色多段堆叠式上下文水位图 (Stacked Context Bar)
* 告别传统的单色进度条！将 1,048,576 Token 窗口以**五色多段堆叠图**呈现：
  * 🟦 **用户输入 (User Tokens)**: `#38bdf8`
  * 🟩 **模型输出 (AI Output)**: `#10b981`
  * 🟪 **深度思考 (Thinking)**: `#c084fc`
  * 🟧 **工具交互与输出 (Tool Results)**: `#f59e0b`
  * ⬜ **系统底层基底 (Base System)**: `#64748b`
* 鼠标悬停色块即刻弹出精准到个位数的 Token 绝对数量与占比，一眼洞察导致上下文膨胀的根源（究竟是超长代码、冗长思考还是工具输出爆炸）。
* **新增子任务追踪**：自动感知 Antigravity 派生运行的 Subagents 并展示子任务数。

---

### 5. ⚡ 硬件兼容扩展与极限开销节流 (Performance & Throttling)
* **AMD / Intel 显卡通用识别**：纯核显或 AMD Radeon 环境下自动识别显卡型号，杜绝信息显示异常。
* **进程采样节流**：仪表盘打开时的 Top 进程扫描优化为 2 秒智能节流采样，自身 CPU 占用进一步稳定在 **< 0.1%**。
* **历史漫游 I/O 优化**：全量历史会话扫描降频至 15 秒，保护磁盘 I/O，活跃会话仍保持 1.0 秒极速响应。
* **横向胶囊栏极值边缘修复**：将横向 HUD 宽度由 980px 微调至 1060px，修复了历史 Token 达到数百万时长文本在右侧边缘被微小截断的视觉 Bug。

已有用户无需重新配置环境，直接拉取最新代码即可享受全部新特性：
